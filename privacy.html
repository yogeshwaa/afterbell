AFTERBELL / PRIVACY · Updated 3 November 2026

Privacy

Afterbell displays a class countdown and timetable from a calendar file you choose. This policy describes the packaged extension. Any website used to host this policy or the Chrome Web Store operates separately under its own policies.

What Afterbell handles

When you choose an ICS timetable, Afterbell reads the file locally and extracts class names and codes, dates and start/end times, rooms, teacher names, and periods. It also remembers the selected file's name. The complete original calendar file, event identifiers and unrelated description text are not saved by Afterbell.

If you choose a background, Afterbell processes the selected image, GIF or video. If you choose a custom reminder sound, it processes that audio file and its name. An encrypted record of recently delivered reminders prevents repeat alerts. It also stores your appearance preferences, school time zone and onboarding choices to provide the interface you selected.

Purpose and consent

This information is used only to display your timetable, countdown, class information, backgrounds and preferences. Selecting a file previews it locally. Timetable, background and settings changes are saved when you select Apply. Onboarding navigation preferences are remembered immediately. Existing local data from earlier versions is encrypted during upgrade.

Break estimates and school-day progress are calculated locally from the imported times. Estimated breaks are not official school information.

No data transmission or sale

The extension does not upload your timetable, media or preferences to the developer or a remote service. Optional desktop notifications pass reminder text to Chrome and your operating system for local display; class details are hidden by default. If you enable details, they can appear on the lock screen or in notification history. Chrome and operating-system settings control those surfaces. It has no analytics, advertisements, tracking, cloud sync or account system. The developer cannot view your imported data through the extension. Afterbell does not sell, share, transfer, or use it for advertising, profiling or lending decisions.

Afterbell follows the Chrome Web Store User Data Policy and its Limited Use restrictions. It uses data only for the disclosed timetable and customisation features.

Local storage and security

Saved timetable details, import and audio filenames, uploaded background/audio, and recent reminder history are encrypted using AES-256-GCM with a fresh random IV for each save. The non-extractable encryption key is stored in the extension's local IndexedDB. Ordinary interface settings are stored in Chrome's local extension storage. Afterbell does not use Chrome sync storage.

This is not a password-protected vault: someone with access to your unlocked browser/profile may access information through the extension. Secure your device and browser profile. Your original downloaded timetable and background files are outside Afterbell and are not changed or deleted by it.

Scripts, fonts and tutorial images are bundled with the extension. Its content security policy blocks network connections and remote scripts. No content scripts read other websites.

Access, correction and deletion

View classes in the timetable; import a corrected export to replace the saved one. Remove timetable or background under Settings, then select Apply. Unapplied previews are discarded when the page closes or reloads.

Settings → Privacy → Delete all local data removes the saved timetable, media, reminder history, settings, onboarding preferences and encryption key, stops Afterbell audio, clears its active notifications, and revokes its optional notification/audio permissions. Uninstalling the extension also removes its local extension data. Data otherwise stays in this browser profile until you replace or remove it. Original files in Downloads remain under your control.

Permissions

storage saves your local settings and encrypted private data. alarms refreshes the toolbar countdown and schedules reminders while Chrome runs. notifications (optional) displays class reminders and explicit test alerts. offscreen (optional) lets a hidden extension document play the short sound you chose while the popup is closed. These optional permissions are requested only when you enable reminders or explicitly test sound/notifications. Afterbell does not request website access, browsing history, cookies, passwords, camera, microphone or location permissions. Opening its own tabs/windows does not grant access to unrelated websites.

Policy changes and questions

Review this page after updates for changes to data handling. For privacy questions, use the developer contact or support link on Afterbell's Chrome Web Store listing when published. This local build has no in-extension support upload or feedback service.
